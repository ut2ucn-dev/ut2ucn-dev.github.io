# Stemik — мобільний застосунок

Нативний застосунок для Android та iPhone (Flutter). Він працює з тією самою
базою Supabase, що й сайт: ті самі таблиці, функції й права доступу (RLS),
тож сайт і застосунок завжди показують одні й ті самі дані.

## Встановлення

**Android.** Відкрийте на телефоні
https://github.com/ut2ucn-dev/ut2ucn-dev.github.io/releases/latest/download/stemik.apk,
дозвольте встановлення з цього джерела і встановіть. Застосунок сам повідомить,
коли вийде нова версія (Ще → Перевірити оновлення). Потрібен Android 7.0+.

**iPhone.** Без платного акаунта Apple Developer ($99/рік) Apple не дозволяє
поширювати застосунки поза App Store, тому CI збирає непідписаний
`stemik-unsigned.ipa` (у тому самому релізі). Два способи встановити:

- **Безкоштовно:** [Sideloadly](https://sideloadly.io) або AltStore на
  комп'ютері підписують `.ipa` вашим Apple ID і ставлять на iPhone. Підпис
  безкоштовного Apple ID діє 7 днів, далі його треба оновити (AltStore робить
  це сам).
- **Для всієї команди:** акаунт Apple Developer → TestFlight. Тоді збірку
  можна роздавати посиланням, і вона оновлюється сама. Для цього в CI треба
  додати сертифікат і профіль підпису.

## Що вміє

- Розклад: тиждень зверху, дні гортаються свайпом; фільтри для адміна
  (викладач, курс, кабінет).
- Картка заняття: П / Н / ВПП, оплата, знижка, друк для онлайн-занять,
  оформлення абонемента; фото робіт з камери, статус друку, «Пробне»;
  екстрені контакти батьків (дзвінок, Viber, Telegram).
- Черга друку, учні (картка з абонементами, історією, коментарями й
  платежами), зарплата за період.
- Для адмінів: заняття (створення, редагування, серії), викладачі (ролі,
  доступ, скидання пароля); для суперадміна ще тарифи й звіт.
- **Офлайн.** Дані зберігаються на телефоні, тож застосунок відкривається і
  без інтернету. Відмітки присутності, оплата, друк, фото робіт і коментарі
  потрапляють у чергу й надсилаються самі, щойно з'явиться зв'язок (значок
  хмаринки вгорі показує, скільки змін чекає). Створення занять, учнів,
  тарифів і акаунтів потребує інтернету.
- **Нагадування** за 5–60 хв до заняття і план на день о 8:00. Плануються на
  телефоні з розкладу, тож працюють без інтернету й без push-сервера.
- **Кабінет батьків.** На екрані входу перемикач «Співробітник / Батьки».
  Батьки входять за номером телефону й паролем, який генерує суперадмін (у
  CRM: Адміністрування → Батьки або картка учня → «Згенерувати пароль»), і
  бачать те саме, що на сайті в `client/`: курси, моделі, оплати й
  абонементи, сертифікати та пробні заняття своїх дітей. Онлайн-оплата поки
  «в розробці». Останні дані зберігаються на телефоні й відкриваються без
  інтернету.

## Як влаштовано

```
lib/
  data/        Supabase API, знімок даних, офлайн-черга (outbox.dart), AppStore
  services/    нагадування, фото з камери, налаштування, оновлення
  ui/          екрани
  util/        правила студії з index.html (формати, сегменти ЗП, друк), дати
  demo/        вигадана студія без сервера — для перегляду й тестів
```

Бізнес-правила з грошима (списання абонемента, ціна, ЗП) рахує база даних —
так само, як для сайту. Застосунок лише показує попередню оцінку, поки зміна
ще не надіслана.

## Розробка

```sh
cd mobile
flutter pub get
flutter analyze && flutter test
flutter run                                        # на телефоні/емуляторі
flutter run -d chrome --dart-define=STEMIK_DEMO=true   # демо без сервера
```

`STEMIK_DEMO_ROLE=teacher` (через `--dart-define`) показує демо очима
викладача. У демо кабінет батьків відкривається з будь-яким телефоном і
паролем.

## Збірка і публікація

`.github/workflows/mobile.yml` при кожній зміні в `mobile/` проганяє аналіз і
тести та збирає APK (Linux) і IPA (macOS):

- з `main` — реліз `mobile-v2.0.<N>`, позначений як останній; на нього ведуть
  посилання вище й перевірка оновлень у застосунку;
- з інших гілок — тестовий реліз `mobile-preview-<гілка>`, який
  перезаписується з кожним push.

### Підпис Android

Усі збірки підписані одним ключем (`android/keystore/stemik-shared.jks`,
пароль `stemik-shared`), тож нові версії ставляться поверх старих. Це той
самий ключ, що й у першої (WebView) версії, і той самий `studio.stemik.app`,
тож новий застосунок встановлюється замість неї. Ключ лежить у публічному
репозиторії й годиться лише для внутрішнього використання. Щоб підписувати
приватним ключем, додайте в Settings → Secrets and variables → Actions:
`STEMIK_KEYSTORE_BASE64` (`base64 -w0 release.jks`), `STEMIK_KEYSTORE_PASSWORD`,
`STEMIK_KEY_ALIAS`, `STEMIK_KEY_PASSWORD`. Після зміни ключа застосунок на
телефонах треба один раз перевстановити.
