# Stemik Admin для Windows

Той самий застосунок адміністратора й суперадміністратора, що й
[Stemik Admin для macOS](MACOS.md): зібраний з того самого коду Flutter, з
тими самими розділами, даними, офлайн-чергою, заставкою з роботом і
переходами. Усе, що описано в [MACOS.md](MACOS.md) в розділі «Що є зараз»,
працює й на Windows. Нижче — лише те, чим Windows-версія відрізняється.

## Встановлення

1. Завантажте
   https://github.com/ut2ucn-dev/ut2ucn-dev.github.io/releases/latest/download/stemik-admin-setup.exe
   і запустіть.
2. Інсталятор не підписаний сертифікатом (він коштує грошей), тож Windows
   SmartScreen при першому запуску покаже «Windows захистив ваш ПК»:
   натисніть **«Додаткові відомості» → «Усе одно запустити»**.
3. Інсталятор українською; права адміністратора не потрібні — застосунок
   ставиться лише для поточного користувача (у
   `%LOCALAPPDATA%\Programs\Stemik Admin`), з ярликом у меню «Пуск» і, за
   бажанням, на робочому столі.

Потрібна Windows 10 або 11 (64-біт). Видалити: Параметри → Програми →
Stemik Admin.

### Якщо Microsoft Defender блокує інсталятор

Defender може видалити `stemik-admin-setup.exe` з повідомленням «Загрозу
заблоковано» — *Program:Win32/Contebrew.A!ml*. Суфікс `!ml` означає, що це
не знайдений вірус, а здогадка машинного навчання: новий інсталятор без
цифрового підпису й без «репутації» (його ще ніхто не завантажував) схожий
для нього на небажану програму. Код застосунку відкритий у цьому
репозиторії, а файл зібрав GitHub Actions. Що можна зробити:

- **Без інсталятора.** Завантажте
  https://github.com/ut2ucn-dev/ut2ucn-dev.github.io/releases/latest/download/stemik-admin-windows.zip,
  розпакуйте папку *Stemik Admin* (наприклад, у Документи) і запустіть
  `stemik_admin.exe`. Ярлик у «Пуск» — правою кнопкою на файлі →
  «Закріпити на початковому екрані». Нова версія — новий ZIP поверх
  старої папки (вхід і дані збережуться).
- **Повернути інсталятор.** Безпека Windows → Захист від вірусів і загроз →
  Журнал захисту → цей запис → **Дії → Дозволити на пристрої**, потім
  завантажте файл ще раз. Робіть це лише для файлу з посилання вище.
- **Повідомити Microsoft про хибне спрацьовування** (адміністратор
  студії, один раз на версію): https://www.microsoft.com/en-us/wdsi/filesubmission →
  «Software developer» → завантажити файл → «Incorrectly detected as
  malware/malicious», вказати назву загрози. Зазвичай Microsoft знімає
  блокування за 1–3 дні.

Остаточно це вирішує лише цифровий підпис коду: підписаний інсталятор
Defender і SmartScreen не чіпають. Найдешевший варіант — Azure Artifact
Signing (≈10 $/міс., потрібна перевірка організації); тоді підпис
додається одним кроком у CI.

**Оновлення.** Застосунок сам перевіряє нову версію (і з меню Файл →
«Перевірити оновлення…») та пропонує завантажити інсталятор. Запустіть
його поверх: він закриє застосунок, оновить, а вхід і дані збережуться —
вони лежать окремо від програми, у `%APPDATA%\Stemik\Stemik Admin`.

## Чим відрізняється від Mac

| | Mac | Windows |
|---|---|---|
| Меню | у рядку меню macOS угорі екрана | під заголовком вікна: Файл, Перейти, Вигляд |
| Клавіші | ⌘1–⌘0, ⌘N, ⌘K, ⌘R… | **Ctrl**+1–0, Ctrl+N, Ctrl+K, Ctrl+R… (те саме, ⌘ → Ctrl) |
| Налаштування, оновлення, вихід | меню «Stemik Admin» | меню «Файл» |
| Картка учня в окремому вікні | так | так (Ctrl+Enter у пошуку) |
| Нагадування про заняття | сповіщення macOS, навіть коли застосунок закрито | сповіщення Windows, **поки застосунок відкритий** (можна згорнути) |
| Сповіщення про дії колег | так | так |
| Вікно пам'ятає розмір і місце | так | так (і чи було розгорнуте) |

Чому нагадування — лише поки застосунок відкритий: Windows не дає
програмам, встановленим не з Microsoft Store, скасовувати вже заплановані
системою сповіщення, тож при зміні розкладу старі нагадування лишалися б.
Тому застосунок сам показує їх у потрібний час. Він розрахований на роботу
весь день: згорніть його, а не закривайте.

Інше:

- Другий запуск не відкриває ще одну копію, а виводить наперед уже
  відкриту.
- Закриття головного вікна спершу дає вікнам учнів дослати зміни (до
  2 секунд), потім закриває застосунок. Що не встигло надіслатися, надішле
  наступний запуск.
- Темний заголовок вікна вмикається разом із темною темою Windows.

## Як влаштовано

- `windows/runner/` — нативна частина (C++):
  - `main.cpp` — головне вікно *Stemik Admin* (1360×860, мін. 1040×680,
    по центру екрана, далі — де було), один екземпляр застосунку, ідентифікатор
    `StemikStudio.StemikAdmin` для панелі завдань і сповіщень;
  - `flutter_window.cpp` — вікно з Flutter: головне чи вікно учня, закриття
    з досиланням змін;
  - `stemik_windows.cpp` — окремі вікна учнів: кожне — свій рушій Flutter з
    тим самим кодом, як і на Mac (`lib/desktop/windows.dart`), з тим самим
    протоколом повідомлень, що й `StemikWindows` у
    `macos/Runner/MainFlutterWindow.swift`;
  - `utils.cpp` — розмір і місце вікна в реєстрі
    (`HKCU\Software\StemikStudio\StemikAdmin`).
- `windows/installer/stemik_admin.iss` — інсталятор (Inno Setup 6).
- `lib/desktop/platform.dart` — `isAdminDesktop` (Mac і Windows),
  `isWindowsApp`, `shortcutLabel()` («⌘N» чи «Ctrl+N»).
- `lib/desktop/desktop_shell.dart` — на Windows ті самі меню, що на Mac,
  малюються як `MenuBar` під заголовком.

Збирає CI (`.github/workflows/mobile.yml`, job `windows` на
`windows-latest`): `flutter build windows`, потім Inno Setup →
`stemik-admin-setup.exe` у релізі поруч з APK, IPA і DMG. Локально на
Windows з Visual Studio 2022 (C++): `flutter build windows`, далі
`iscc windows\installer\stemik_admin.iss`.
