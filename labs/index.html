Як розгорнути етап

  1. Створіть окремий навчальний проєкт Supabase (не робочий).
  2. SQL Editor → по черзі виконайте файли з папки етапу docs/db-labs/stages/lrN/db/, починаючи з ЛР1.
  3. Project Settings → API: впишіть Project URL і ключ anon у labs/config.js.
  4. Відкрийте версію сайту потрібного етапу.
