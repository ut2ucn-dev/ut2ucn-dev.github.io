# Stemik для Android

Нативний Android-застосунок, який відкриває сайт https://ut2ucn-dev.github.io/
у повноекранному WebView. Увесь інтерфейс і логіка — це той самий `index.html`,
тому кожна зміна сайту одразу з'являється в застосунку, без нового APK.

Що вміє обгортка:

- вхід і сесія зберігаються між запусками;
- «Додати фото» пропонує камеру або галерею;
- посилання на інші сайти, Instagram і `tel:` відкриваються у відповідних застосунках;
- кнопка «Назад» повертає на попередню сторінку;
- системні панелі підлаштовуються під світлу/темну тему сайту;
- без інтернету показує екран «Немає з'єднання» з кнопкою повтору.

## Встановлення

1. Відкрийте на телефоні https://ut2ucn-dev.github.io/downloads/stemik.apk
   (або перешліть собі файл `downloads/stemik.apk`).
2. Дозвольте встановлення з цього джерела, коли Android запитає.
3. Встановіть. Потрібен Android 7.0 або новіший.

## Збірка

APK збирає GitHub Actions (`.github/workflows/android.yml`) при кожній зміні в
`android/` і комітить результат у `downloads/stemik.apk` на тій самій гілці.
Запустити вручну: Actions → «Android APK» → Run workflow.

Локально (потрібні JDK 17+ і Android SDK):

```sh
cd android
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

## Підпис

Щоб нові версії встановлювались поверх старих, усі збірки підписуються одним
ключем. За замовчуванням це `keystore/stemik-shared.jks` (пароль `stemik-shared`) —
він лежить у публічному репозиторії, тож підходить лише для внутрішнього
використання.

Щоб підписувати власним приватним ключем, додайте в Settings → Secrets and
variables → Actions:

| Секрет | Значення |
| --- | --- |
| `STEMIK_KEYSTORE_BASE64` | `base64 -w0 release.jks` |
| `STEMIK_KEYSTORE_PASSWORD` | пароль сховища |
| `STEMIK_KEY_ALIAS` | псевдонім ключа |
| `STEMIK_KEY_PASSWORD` | пароль ключа |

Після зміни ключа застосунок на телефонах доведеться один раз видалити й
встановити заново.
