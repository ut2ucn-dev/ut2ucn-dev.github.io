Етап ЛР2

SQL для навчального проєкту Supabase

Виконується після файлів етапу ЛР1, по черзі в SQL Editor навчального (не робочого) проєкту. Поточна схема з ЛР1 лишається в схемі public, модель створюється поруч — у схемі stemik.

ФайлЩо робить
lr2_01_schema.sqlФізична модель: схема stemik, 18 таблиць, ключі, обмеження, каскадні дії, індекси (DDL з протоколу ЛР2).
lr2_02_seed.sqlТестові дані для перевірки моделі (102 рядки).
lr2_03_site_api.sqlФункції для сайту: lab_lr2_model() — каталог моделі; lab_lr2_constraint_tests() — 10 перевірок обмежень з відкатом змін.
Один проєкт Supabase разом із CRM? Тоді виконуйте не ці файли, а їхній варіант з теки db/one-project/: lr2_01_schema.sql, lr2_02_seed.sql, lr2_03_site_api.sql. Вони створюють модель в окремій схемі stemik_lr2 і не зачіпають схему stemik, на якій працює CRM.
