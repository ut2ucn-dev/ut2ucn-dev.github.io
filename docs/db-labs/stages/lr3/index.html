Етап ЛР3

SQL для навчального проєкту Supabase

Виконується після етапів ЛР1 і ЛР2. Схема stemik створюється заново — з іменованими обмеженнями — і наповнюється даними з копії робочої бази (схема public).

ФайлЩо робить
lr3_01_create_tables.sqlCREATE SCHEMA і 18 таблиць CREATE TABLE у порядку залежностей, 86 іменованих обмежень.
lr3_02_migrate.sqlINSERT … SELECT з копії робочої бази в модель з очищенням (2480 рядків) і звіт перенесення.
lr3_03_site_api.sqlФункції для сайту: звіт перенесення, перегляд даних таблиць, 14 демонстрацій ALTER/UPDATE/DELETE/TRUNCATE/DROP з відкатом.
lr3_04_alter.sqlТри зміни структури, що лишаються для ЛР4 (hire_date, тип телефону й тривалості).

Повна демонстрація в psql (CREATE DATABASE, \timing тощо) — скрипти lab3/sql/00…07, описані в протоколі ЛР3.
