Етап ЛР4

SQL для навчального проєкту Supabase

Виконується після етапу ЛР3. Структура й дані моделі не змінюються: додаються два представлення і каталог із 24 запитів, які сайт виконує за номером.

ФайлЩо робить
lr4_01_views.sqlПредставлення v_schedule (розклад) і v_subscription_status (стан абонементів з телефонами батьків).
lr4_02_site_api.sqlТаблиця lab_query з 24 запитами й бізнес-задачами; функції lab_lr4_catalog(), lab_lr4_run(id), lab_lr4_overview(). Сайт передає лише номер запиту — довільний SQL виконати не можна.

Ті самі запити для psql, згруповані за завданнями методичних вказівок, — у скриптах docs/db-labs/lab4/sql/01_simple.sql … 06_window.sql, описаних у протоколі ЛР4.
