# Захист початку роботи над проєктом — комплект файлів

| Файл | Що це |
|---|---|
| `Презентація_Захист.pptx` / `.pdf` | 22 слайди: структура й модель даних, 3НФ і НФБК, ключі, розрив M:N, наповнення, 3 пошукові запити, вебінтерфейс адміністратора. Покрокові нотатки доповідача — у кожному слайді (режим доповідача PowerPoint). |
| `Текст_доповіді.docx` / `.pdf` | ті самі нотатки одним документом + підготовка перед захистом + ймовірні запитання викладача з відповідями |
| `stemik-crm-demo.zip` | базова версія сайту CRM з SQL-скриптами; інструкція — `README.md` в архіві |
| `img/` | усі схеми й скриншоти у високій роздільності (див. нижче) |

Вихідні файли сайту лежать у репозиторії в каталозі [`crm-demo/`](../../../crm-demo/).
